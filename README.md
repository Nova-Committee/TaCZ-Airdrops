# TaCZ Airdrops

Adds dedicated weapon supply airdrops containing TaCZ guns, attachments, and ammunition to Airdrop: Supply Drops.

## Installation

Download the mod JAR from CurseForge and place it in `mods` on both server and clients, together with:

- Minecraft 1.20.1 / Forge 47.3+
- [Airdrop: Supply Drops](https://www.curseforge.com/minecraft/mc-mods/airdrop-supply-drops) 1.0.14+
- [Timeless and Classics Zero (TaCZ)](https://github.com/MCModderAnchor/TACZ)

Includes dedicated crate and parachute models, equipped weapon kits, individual guns, attachments, ammunition, and ammo boxes. Supply names support English and Simplified Chinese.

Version: **0.1.0**. This repository contains the core runtime resources under `resource_mod/`.

Weapon Supply v3 artwork was supplied for this integration by the Airdrop author.
